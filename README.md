# 🪨 Rock Paper Scissors — RPS Arena

A polished, responsive Rock Paper Scissors game built with vanilla HTML, CSS and JavaScript.

## ✨ Features

- 🎮 Classic and Adaptive AI modes
- 🤖 Easy, Normal, Hard and Master difficulty
- 🏆 Best-of-3, 5, 7 and 10 matches
- 🔥 Win streaks and achievements
- 📊 Persistent stats and win rate
- 📜 Recent-round history
- 🌙 Dark / light theme
- 🔊 Optional sound feedback
- ⌨️ Keyboard controls: R / P / S
- 📱 Responsive mobile layout
- 💾 LocalStorage persistence
- ⚡ Zero dependencies

## 🚀 Run

Open `index.html` directly, or serve the folder with any static web server.

## 🌐 GitHub Pages

Enable **Settings → Pages → Deploy from branch → main → / (root)** to publish the game.

## 🧱 Stack

HTML5 · CSS3 · Vanilla JavaScript · Web Audio API · Local Storage
